1	# Embedded mode: Tableau-hosted viz/dashboard extensions
2	
3	Embedded extensions are raw HTML/JS/CSS that Tableau serves from a
4	package-relative path (`content/ext/...`). This is the preferred mode for new
5	viz/dashboard work: the user has full control over the code, Tableau hosts it
